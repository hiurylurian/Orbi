# ORBI Gestor — demonstração v26

Página pública de demonstração visual de Cadastro Padrão, Parametrização, fluxo nativo e Estoque em Movimento.

Todos os dados são sintéticos. Este site não se conecta ao ORBI operacional, banco de dados, ERP ou PDV e não executa movimentações.

A publicação é feita pelo GitHub Pages a partir de `index.html`.
